# Arduino Claw PCB Redesign

## Overview

This project involved redesigning the electrical connections for an Arduino-controlled claw developed as part of a team-based engineering project. After identifying unreliable wire connections during testing, I independently developed a PCB redesign in KiCad to improve connection stability and reduce wiring issues.

## Problem Statement

During testing, loose wire connections caused inconsistent system performance. The existing wiring arrangement was unreliable, making it difficult to ensure consistent operation of the claw's electronic components.

## Design Approach

* **PCB Design:** Used KiCad to develop a PCB redesign aimed at improving wiring organization and connection reliability.
* **Hardware Integration:** Considered the electrical connections between the Arduino and the claw's electronic components.
* **Reliability:** Focused on reducing loose connections and improving the overall organization of the circuit.

## Tools Used

* KiCad
* Arduino
* Embedded C/C++

## Engineering Challenges

The primary challenge was identifying hardware connectivity as a potential source of system unreliability and developing a more structured electrical connection solution. The redesign focused on addressing the wiring issues observed during system testing.

## Project Outcome

Developed a PCB redesign concept to address wiring instability in the Arduino-controlled claw. This project strengthened my understanding of PCB design, hardware integration, and the importance of reliable electrical connections in embedded systems.

## Future Improvements

* Manufacture the PCB and validate the physical design.
* Test connection reliability under repeated claw operation.
* Refine the layout based on assembly and testing results.
